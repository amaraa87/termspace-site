# termspace-site

Public landing page for **Termspace**, a native macOS terminal workspace for AI coding agents, shells and SSH. It is static HTML with no build step, published to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main` at https://amaraa87.github.io/termspace-site/. The DMG is a GitHub release asset of this repo. All asset paths are relative, so the site works under `/termspace-site/` or on a custom domain. To ship a new version, upload the DMG to a new release and then update the release facts. In `index.html` they live in the `data-version`, `data-size`, `data-sha`, `data-url` and `data-file` attributes on `<body>`, which `assets/js/site.js` copies into every element marked `data-r` / `data-r-href`. The same values also appear as static fallback text in those elements: the eyebrow, the download button (href and the `v0.4.0` label), the file name, size and SHA-256 under it, the Install step 1 link, and the footer. `grep -nE '0\.4\.0|13\.0 MB|637112' index.html` finds all of them. The version is also drawn into `assets/img/og.png`: change it in `tools/og.html`, then `"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --hide-scrollbars --force-device-scale-factor=1 --window-size=1200,630 --virtual-time-budget=4000 --screenshot=assets/img/og.png "file://$PWD/tools/og.html"`.
